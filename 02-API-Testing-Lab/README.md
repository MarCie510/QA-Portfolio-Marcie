# API Testing Lab — Postman & Qase.io

Comprehensive API testing projects integrating professional test design in Qase.io with automated execution in Postman.

---

## 🏗️ Test Management (Qase.io)
This lab follows a **Design-First** approach. The scenarios for the modern REST suites (Booking & Trello) were modeled in Qase to ensure 100% coverage of business rules and edge cases.

* **Trazability:** Every Postman request is mapped to a Test Case ID.
* **Master Documentation:** The full test design export is available in:
    * [**JSON Format (Professional Design)**](./qase-test-design/QA_API_Design_Master.json)
    * [**XML Format (Interoperability)**](./qase-test-design/QA_API_Design_Master.xml)
